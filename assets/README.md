## Format Gambar
- **Format**: JPG atau PNG
- **Maksimal**: 500 KB per gambar (untuk loading cepat)
- **Rekomendasi Kompresi**: Gunakan tool seperti TinyPNG atau ImageOptimizer

## Catatan
- Nama file harus sesuai persis (case-sensitive di Linux/Mac)
- Gunakan huruf kecil dan tanda hubung (-) untuk spasi dalam nama file
- Jika gambar tidak ditemukan, halaman akan menampilkan broken image
